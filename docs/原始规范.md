# WenXiBuddy · UI 设计规范分析

> 基于产品界面的逆向工程，提炼为可执行的设计系统（Design Token + 布局 + 组件 + 动效），并据此重建一个高保真、可交互的示例页面。

## 1. 设计语言定位
一套**深色优先、单色强调**的生产力工具界面。气质冷峻、信息密度高，靠"荧光翠"作为唯一情绪出口；用 **3.5D 透视文件袋（Cover-Flow 环绕）** 作为视觉锚点，把枯燥的任务列表转译为可"翻阅"的空间物件。整体克制——细发丝边、点阵底纹、低饱和玻璃，拒绝装饰性渐变与圆角滥用。

## 2. 色彩系统（Color Tokens）

| Token | 值（水晶文件袋/默认黑） | 用途 |
|---|---|---|
| `--bg` | `#050607` | 应用底色 |
| `--panel` / `--panel-2` | `#0E1012` / `#14171A` | 一级/二级面板 |
| `--line` / `--line-2` | `rgba(255,255,255,.07)` / `.12` | 发丝分隔线 |
| `--text` / `--muted` / `--faint` | `#F3F5F4` / `#8B9390` / `#5A625F` | 三级文字层级 |
| `--accent` / `--accent-2` | `#35E07C` / `#18C463` | 品牌翠（按钮/完成/选中） |
| `--prog` / `--over` | `#F5A524` / `#FF5468` | 进行中 / 逾期 |
| 分组色 绿/紫/蓝 | `#35E07C` / `#A06BFF` / `#4D8DFF` | 项目分组与对应文件袋、甘特条 |

**三主题**通过 `data-theme` 在根节点切换同一套 token：`crystal`（纯黑）、`jade`（深绿环境光）、`light`（macOS 浅色，文字/面板反相，强调翠保持不变）。

## 3. 字体（Type）
- **Display**：`Space Grotesk`（标题、品牌、统计巨数）— 几何、有棱角的科技感。
- **Body**：`Manrope` + `Noto Sans SC`（中英文正文）— 高可读无衬线。
- 层级靠**字号与字重的强对比**而非颜色：统计数 44px/800，标题 15px/700，描述 11.5px/400 灰。

## 4. 形状 / 间距 / 阴影
- 圆角分级：容器 `16–20px`、卡片 `12–14px`、控件 `8–10px`、按钮胶囊 `999px`（**不**全站统一大圆角）。
- 边框统一 1px 发丝线；面板用极轻投影 `0 24px 60px rgba(0,0,0,.45)` 抬升。
- 玻璃仅用于 3D 文件袋与悬浮卡：`backdrop-filter: blur` + 半透明填充 + 内发光，**不**铺满全站。

## 5. 布局（App Shell · 三栏）
左导航 `232px`（可收窄至 `72px` 图标态）｜ 中工作区 `flex` ｜ 右详情 `360px`。
中区纵向：标题条 → 4 列统计卡 → 看板（左 *项目分组树* + 右 *文件袋舞台*）→ *甘特时间线*。

## 6. 组件清单
统计卡、搜索框、胶囊主按钮、Toggle 开关、下拉/筛选条、视图切换（列表/卡片/文件袋）、分组折叠树、**3.5D Cover-Flow 文件袋**、悬浮信息卡、甘特条/标签、详情字段网格、逾期警示条、附件卡、底部 Toast、设置模态。

## 7. 动效 / 微交互
Cover-Flow 自动环绕（hover 暂停、点击定位、键盘左右）；统计数 count-up；区块滚动 reveal；Toggle/视图/主题平滑过渡；左栏鼠标移出自动收窄；操作后底部 Toast 反馈；"静态省电"档可冻结全部持续动画。

    if(raw>half)raw-=N; if(raw<-half)raw+=N;
    const a=Math.abs(raw);
    const x=raw*118*(1-Math.min(a,4)*0.06);
    const z=-a*a*46;
    const ry=Math.max(-58,Math.min(58,-raw*40));
    const sc=raw===0?1.16:1-a*0.05;
    const el=items[i];
    el.style.transform=`translateX(${x}px) translateZ(${z}px) rotateY(${ry}deg) scale(${sc})`;
    el.style.zIndex=String(100-a);
    el.style.opacity=a>3?0:1;
    el.classList.toggle('active',raw===0);
    el.classList.toggle('dim',raw!==0);
  }
}
